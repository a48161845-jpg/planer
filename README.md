# Планер

Приложение для телефона и планшета (PWA) + Telegram-бот. Работает как обычное приложение, без интернета,
и как мини-приложение внутри Telegram. Собирается и публикуется через GitHub Actions — компьютер не нужен.

```
web/                         приложение (index.html, css/, js/, sw.js, manifest, иконка)
bot/                         Telegram-бот (aiogram 3), bot/files/planner.html — файл для /app
tools/                       сборка одного файла
.github/workflows/pages.yml  автопубликация на GitHub Pages
```

## Что есть в приложении

- **Главная:** дата, время, приветствие, погода, прогресс дня, быстрое добавление («завтра в 16:00 сдать отчёт»), ближайшие напоминания, задачи на сегодня, календарь на 7 дней, виджет привычек.
- **Напоминания:** разовые и повторяющиеся (каждый день, по будням, по дням недели, раз в неделю/месяц), несколько уведомлений (в срок + за 5/10/30/60 мин, за день), отложить на 5/10/30/60 минут, приоритеты, категории с цветами, история, голосовой ввод.
- **Задачи:** приоритеты, сроки, подзадачи, повторы, проекты, процент выполнения, архив, перенос просроченных.
- **Календарь:** месяц / неделя / день, события, дни рождения, праздники РФ, цвета категорий, еженедельное расписание, импорт и экспорт .ics.
- **Привычки:** серии, статистика за неделю и месяц, календарь активности, цели «каждый день» и «N раз в неделю», напоминания.
- **Заметки:** текст, чек-листы, списки покупок, теги, закрепление, поиск, фото.
- **Финансы:** доходы и расходы, категории, бюджет месяца, цели накоплений, статистика, история, экспорт CSV.
- **Инструменты:** таймеры, секундомер, Pomodoro, вода, цели с этапами, статистика, дневник, сейф (шифрование паролем), обратный отсчёт дат.
- **Помощник (локальный):** создание из обычного текста, раскладка дел по свободным окнам недели, разбиение большой задачи, поиск конфликтов, итоги недели.
- **Значки:** плоские двухцветные 2D-значки разделов и привычек (46 штук). Свои значки: любой эмодзи или своя картинка. Для привычек: форма привычки, для разделов: «Настройки → Значки разделов».
- **Поиск** по задачам, напоминаниям, событиям, заметкам и целям (значок лупы в шапке). Удаление можно отменить кнопкой «Отменить». Аватарка приложения — в шапке и на экране входа.
- **Главная** разделена на «Сегодня / Неделя / Итоги»: быстрые действия, вода, диаграммы недели, показатели, дни рождения.
- **Вкладки:** Главная, Календарь, Задачи, Привычки, Финансы, Ещё. Нижнее меню (до 5 разделов) и блоки главного экрана настраиваются: «Настройки → Нижнее меню / Главный экран». На главный экран можно вынести заметки, финансы, цели, дни рождения, Pomodoro и другое.
- **Настройки:** тёмная / светлая / авто тема, 6 цветовых схем (Аврора, Океан, Закат, Лес, Слива, Графит), порядок разделов, PIN-код, звук, категории, резервная копия, облако Telegram, офлайн-режим.

## 1. Публикация (только телефон/планшет)

1. Создайте публичный репозиторий на github.com и загрузите все файлы, сохранив папки
   (Add file → Upload files; папку `.github` лучше создавать через «Create new file» с путём `.github/workflows/pages.yml`).
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Вкладка Actions → дождитесь зелёной галочки у «Deploy Planner to GitHub Pages» (при пуше в `main` запускается сам; можно вручную: Run workflow).
4. Адрес: `https://<логин>.github.io/<репозиторий>/`

## 2. Установка на телефон

- Android (Chrome): открыть адрес → меню ⋮ → «Установить приложение».
- iPhone (Safari): Поделиться → «На экран Домой».

Затем «Ещё → Настройки → Разрешить уведомления».

## 3. Бот и вход

Приложение работает через **один бот — ваш**. Имя бота вписывается один раз в `web/config.js`:
```js
window.CFG = { BOT: "my_planner_bot" };
```

### Запуск бота
1. В @BotFather создайте бота и получите токен.
2. Запуск (Termux подойдёт):
   ```
   pip install -r bot/requirements.txt
   export BOT_TOKEN="токен"
   export WEBAPP_URL="https://<логин>.github.io/<репозиторий>/"
   export DEFAULT_TZ=420
   export ADMIN_ID=ваш_telegram_id      # узнать: напишите боту /id
   python bot/bot.py
   ```

### Вход и синхронизация
- **Через Telegram:** в боте нажмите /start и «Завершить регистрацию»: приложение определит часовой пояс само (например, Asia/Krasnoyarsk). Внутри Telegram приложение входит автоматически.
- **Синхронизация идёт по аккаунту Telegram** (облако Telegram, без сервера): при открытии и после изменений приложение само сравнивает копии, побеждает более новая. На втором устройстве достаточно открыть приложение через бота.
- **Без входа** (кнопка на первом экране): синхронизации нет, данные только на этом устройстве, резервная копия и выгрузка данных (JSON, CSV, .ics) недоступны.
- Установленное на главный экран приложение (вне Telegram) работает в режиме без входа; для синхронизации открывайте его через бота.

### Админ-панель в Telegram
Команда `/admin` (только для `ADMIN_ID`, можно несколько через запятую): сводка (всего, регистрации, новые за день, неделю и месяц, активные за 24 ч / 7 / 30 дн), список пользователей с карточкой каждого (регистрация, последнее обращение, синхронизация, часовой пояс, число напоминаний, задач, событий, привычек, операций), регистрации по дням, часовые пояса. Бот хранит только Telegram-ID, имя и данные, которые вы синхронизировали; username не сохраняется.

### Приложение для Android (APK)
Вкладка **Actions → Build Android APK → Run workflow**. Через 5–10 минут во вкладке **Releases** репозитория появится `planner.apk`: скачайте и установите (разрешите установку из неизвестных источников). Если положить его в `bot/files/planner.apk`, бот будет присылать его командой `/apk`.
APK — это оболочка, внутри которой работает то же приложение (автономно, без интернета). **Уведомления в APK приходят при закрытом приложении**: напоминания (в срок и заранее), события, таймеры планируются на сам телефон. При первом запуске разрешите уведомления. Вход через Telegram и синхронизация работают только внутри Telegram; в APK приложение работает в режиме «без входа».

### Файл приложения
Команда `/app` присылает пользователю файл `planner.html` (всё приложение в одном файле, открывается в браузере телефона). Файл лежит в `bot/files/`; после изменений в `web/` пересоберите его: `python tools/build_single.py`. Аватарка: положите `web/avatar.png` и пересоберите файл, она подставится на экран входа и в профиль.

### Приложение → бот
Кнопка «Синхронизация» открывает приложение; в «Ещё → Telegram» нажмите «Отправить боту…». Бот запомнит напоминания (в срок и заранее), расписание, события, дни рождения, привычки и список задач, и будет присылать уведомления, когда приложение закрыто. После правок в приложении синхронизацию нужно повторить.

### Бот → приложение
Команды в чате создают данные, которые затем нужно принять в приложении: напишите `/sync` и нажмите «Принять пакет». Так передаются задачи, расходы и доходы, вода, отметки привычек и напоминания, созданные в боте. `/resync` повторно присылает данные за 3 дня.

### Команды бота
```
/add 15м текст | 2ч | 1д | 16:30 | завтра 9:00 — напоминание
/list, /clear      /today — план на сегодня
/task, /tasks, /done 3
/habit             /water 250
/expense 450 еда обед    /income 5000 зарплата
/stats             /digest 08:00 (или off)
/me                /sync, /resync
```

## Ограничения (честно)

- Закрытая PWA не может надёжно срабатывать в фоне — поэтому напоминания в фоне доставляет бот.
- Помощник работает по правилам, без языковой модели; подключить настоящий ИИ можно только через серверную часть с ключом.
- Google Календарь: прямой синхронизации по аккаунту нет (нужен сервер с OAuth). Работает обмен файлами .ics.
- Вход по биометрии недоступен для веб-приложения, есть PIN.
- Синхронизация между устройствами: через копию в облаке Telegram или экспорт/импорт JSON.
- Бот хранит данные в `planner.db` рядом со скриптом; сохраняйте файл при переезде.


## Вход по ID и уведомления через бота
- В приложении у каждого пользователя есть ID вида `PL-XXXXXX`. На первом экране нажмите «Скопировать команду», отправьте её боту — бот запомнит ID, определит часовой пояс и ответит кодом `K1.…`. Код вставляется в приложении. Никаких переходов на сайты.
- Уведомления настраиваются в «Аккаунт и бот → Уведомления через бота» и командой `/notify` в чате. Чтобы бот присылал напоминания, отправьте ему данные: кнопка «Скопировать данные для бота» → вставить в чат (внутри Telegram — кнопка отправки).
